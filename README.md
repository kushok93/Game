# Морской бой

Играть: **https://kushok93.github.io/Game/**

Классический морской бой в браузере: против компьютера или онлайн с другом. Работает на компьютере и телефоне, ничего устанавливать не нужно.

## Как играть с другом
1. Нажмите «Создать игру с другом» — появится код комнаты и ссылка.
2. Отправьте ссылку другу (или продиктуйте код — он введёт его в поле «Подключиться»).
3. Оба расставляют флот и жмут «Начать игру». Первым ходит создатель комнаты, в реванше — по очереди.

Соединение идёт напрямую между браузерами (WebRTC через [PeerJS](https://peerjs.com/)), поле соперника не передаётся — видны только результаты выстрелов.

## Правила
- Поле 10×10, флот: 1×4, 2×3, 3×2, 4×1. Корабли не касаются друг друга даже углами.
- Попадание даёт право на ещё один выстрел. Клетки вокруг потопленного корабля закрываются автоматически.

## Управление
- ЛКМ — поставить корабль, ПКМ или **R** — повернуть, «Случайно» — расставить автоматически.
